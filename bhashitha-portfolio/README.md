# Kalva Lakshmi Bhashitha — Developer Portfolio

A minimal, responsive React portfolio with a warm cream background with olive, charcoal, and brown accents, project cards, experience, achievements, skills, certifications, and contact section.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown by Vite.

To create a production build:

```bash
npm run build
```

## Personalize before publishing

Open `src/main.jsx` and update the constants inside `App()`:

- Update the project repository links in the `projects` array if they change.
- `githubUrl`, `linkedinUrl`, and `email` are already configured.
- The résumé is available at `public/resume.pdf`.

Verify the internship description reflects your actual responsibilities before publishing. Add certificate verification links if available.

## Important notes

- No JavaScript is listed in the technical skills section.
- The portfolio itself is implemented in React, which uses JavaScript internally.
- Verify each certification's exact official title and provider before publishing.
- Add only technologies and features you have actually used.


Theme update: warm cream, charcoal, olive green, and brown. The design does not require a profile photo or monogram logo.
